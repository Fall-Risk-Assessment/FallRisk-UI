# รายงานความก้าวหน้า งวดที่ 1
## กิจกรรมที่ 7 ต้นแบบการประเมินความเสี่ยงหกล้ม และ กิจกรรมที่ 8 ต้นแบบกิจกรรมออกกำลังกาย

### วิธีการดำเนินการ
1. การออกแบบสถาปัตยกรรมของระบบทั้งในส่วนฮาร์ดแวร์ IoT 
การศึกษาวิธีการการส่งผ่านและจัดเก็บข้อมูล การออกแบบซอร์ฟแวร์ในรูปแบบ web application 
เพื่อบันทึกและแสดงผลข้อมูล

2. การทบทวนวรรณกรรมที่เกี่ยวข้อง และรวบรวมความคิดเห็นจากผู้เชี่ยวชาญทั้งด้านการแพทย์ 
และวิศวกรรม เพื่อออกแบบท่าทางการออกกำลังกาย และวิธีการประเมินความเสี่ยงหกล้ม (fall risk 
assessment) ที่เหมาะสมในการใช้งานจริงในโครงการ พร้อมทั้งวิธีการทวนสอบ (validation tools) 
ที่เหมาะสมมีความเชื่อถือได้ในทางการแพทย์

3. การทำการบันทึกข้อมูลจากตัวอย่างอาสาสมัคร และการติดป้ายกำกับให้กับข้อมูล (data annotation) 
ตามข้อ 2.

4. การสร้างโมเดลปัญญาประดิษฐ์เพื่อวิเคราะห์ข้อมูล ซึ่งการประมวลผลข้อมูลประกอบด้วย pre-processing (เช่น การลดสัญญาณรบกวน, การกรองข้อมูล, การปรับความละเอียดของข้อมูล, การทำ data normalization เป็นต้น), การสร้างโมเดล, การทวนสอบและทดสอบโมเดล 
เพื่อให้ได้ประสิทธิภาพในการจำแนกท่าทางการออกกำลังกายตามตัวแบบ 
และการประเมินความเสี่ยงหกล้ม

5. การพัฒนาเว็บแอพพลิเคชั่นและระบบฐานข้อมูลเพื่อแสดงผลและจัดเก็บข้อมูล และมี user interface 
ที่สร้างประสบการณ์ที่ใช้งานได้และมีการประเมินความพึงพอใจ 
เพื่อเป็นต้นแบบในการต่อยอดพัฒนาระบบต่อไป

ภาพรวมของกิจกรรมที่ 7 ต้นแบบการประเมินความเสี่ยงหกล้ม และ กิจกรรมที่ 8 
ต้นแบบกิจกรรมออกกำลังกาย แสดงดังรูปที่ 1 และ 2 ตามลำดับ

รูปที่ 1 ภาพรวมของการพัฒนาต้นแบบการประเมินความเสี่ยงหกล้ม
รูปที่ 2 ภาพรวมของการพัฒนาต้นแบบกิจกรรมออกกำลังกาย

### ข้อกำหนดด้านฮาร์ดแวร์ในเบื้องต้น 
(หมายเหตุ: อาจมีการเปลี่ยนแปลงได้ตามความเหมาะสมในเพื่อปรับให้เข้ากับความต้องการและการพัฒนาจริงในโครงการ)

1. ระบบเซ็นเซอร์วัดแรงกด
แผ่นวัดแรงกดประกอบด้วย Sensing array ขนาดประมาณ 32×32 pixels 
โดยสร้างจากวัสดุที่นำไฟฟ้าและวัสดุที่มีการเปลี่ยนแปลงความต้านทานไฟฟ้าได้เมื่อได้รับแรงกด เช่น Velostat, Carbon-based, MXene-based เป็นต้น ซึ่งระบบจะเชื่อมต่อผ่าน microcontroller 
สามารถส่งค่าความต้านทานและกระแสไฟฟ้าสู่หน่วยประมวลผลได้

2. ระบบตรวจจับการเคลื่อนไหว
แนวคิดในการออกแบบ แนวคิดในการออกแบบระบบ Camera Module 
สำหรับการประเมินความเสี่ยงการหกล้ม 
มีเป้าหมายเพื่อสนับสนุนการเก็บข้อมูลการเคลื่อนไหวและพฤติกรรมการทรงตัวของผู้สูงอายุอย่างเป็นระบบ ปลอดภัย และไม่รบกวนในการใช้งาน 
โดยมุ่งเน้นให้ระบบสามารถทำงานได้จริงในบริบทของการประเมินในห้องปฏิบัติการโรงพยาบาลหรือในชุมชน และประยุกต์ใช้ในระบบจำแนกท่าทางการออกกำลังกายตามตัวแบบได้

ระบบถูกออกแบบให้ใช้ เซ็นเซอร์หลายรูปแบบ (Multimodal Sensing) 
โดยผสานการทำงานของกล้องวิดีโอและเซ็นเซอร์เรดาร์ mmWave 
เพื่อให้สามารถตรวจจับการเคลื่อนไหวของร่างกายได้อย่างต่อเนื่องและมีความน่าเชื่อถือกล้องทำหน้าที่บันทึกภาพเพื่อสนับสนุนการวิเคราะห์ท่าทางและบริบทของการเคลื่อนไหว ขณะที่เซ็นเซอร์ mmWave 
ทำหน้าที่เป็นตัวตรวจจับการเคลื่อนไหวหลักซึ่งไม่ขึ้นกับสภาพแสงและช่วยลดการพึ่งพาข้อมูลภาพที่อาจกระทบต่อความเป็นส่วนตัวของผู้ใช้งาน

เพื่อให้ระบบสามารถติดตามผู้เข้ารับการประเมินได้อย่างเหมาะสม กล้องถูกติดตั้งบน 
กลไกการหมุนแบบแกนเดียว (Single-Axis Pan Mechanism) 
ซึ่งสามารถปรับมุมมองในแนวนอนเพื่อติดตามการเคลื่อนไหวของผู้ใช้งานได้โดยอัตโนมัติ 
แนวคิดนี้ช่วยลดความจำเป็นในการติดตั้งกล้องหลายตัว เพิ่มความยืดหยุ่นในการใช้งาน 
และทำให้ระบบมีโครงสร้างที่เรียบง่ายและน้ำหนักเบา

ในด้านการออกแบบเชิงกายภาพ โมดูลกล้องถูกออกแบบให้มีขนาดกะทัดรัด น้ำหนักเบา 
และรองรับการติดตั้งแบบทั่วไป เช่น การติดตั้งบนขาตั้งหรือโครงยึด 
เพื่อให้สามารถนำไปใช้งานในสถานที่ต่าง ๆ ได้สะดวก 
โดยมุ่งหมายให้ผู้สูงอายุที่เข้ารับการประเมินจะไม่รู้สึกถูกรบกวน

นอกจากนี้ ระบบยังคำนึงถึง ความปลอดภัยและความเป็นส่วนตัวของข้อมูล 
โดยจำกัดการใช้งานข้อมูลภาพให้อยู่ในขอบเขตของการวิเคราะห์การเคลื่อนไหวเท่านั้น 
ไม่มุ่งเน้นการระบุตัวตนบุคคล และออกแบบให้สามารถทำงานร่วมกับการประมวลผลบนอุปกรณ์ (Edge Processing) เพื่อลดการส่งข้อมูลออกนอกระบบ

โมดูลกล้องติดตามการเคลื่อนไหวสำหรับต้นแบบ (รุ่นที่ 1) ของระบบประเมินความเสี่ยงการหกล้ม 
มีข้อกำหนดทางฮาร์ดแวร์ (Hardware Specification) ดังนี้…

b) ระบบประมวลผลที่คาดว่าจะใช้ควบคู่กับ Camera Module
รูปที่ 3 ระบบ Camera Module สำหรับการประเมินความเสี่ยงล้ม และจำแนกท่าทางการออกกำลังกาย

#### 2.1 ระบบกล้อง (Camera Subsystem)
รุ่นกล้อง: Logitech B100 Web Camera
ชนิดเซ็นเซอร์ภาพ: CMOS
ความละเอียดสูงสุด: ระดับ VGA (สูงสุด 640 × 480 พิกเซล)
อัตราเฟรม: สูงสุด 30 เฟรมต่อวินาที
อินเทอร์เฟซ: USB
หน้าที่การทำงาน: ใช้บันทึกภาพการเคลื่อนไหวของผู้เข้าร่วมทดสอบ
สนับสนุนการวิเคราะห์ท่าทางและการเคลื่อนไหวร่วมกับข้อมูลจากเซ็นเซอร์ mmWave

#### 2.2 ระบบตรวจจับการเคลื่อนไหว (Motion Sensing Subsystem)
ชนิดเซ็นเซอร์: เซ็นเซอร์เรดาร์ mmWave
หลักการทำงาน: การตรวจจับการเคลื่อนไหวของมนุษย์ด้วยคลื่นเรดาร์
ความสามารถ: ตรวจจับการมีอยู่ของมนุษย์ ตรวจจับการเคลื่อนไหวและรูปแบบการเคลื่อนไหว
สภาพแวดล้อมการใช้งาน: ภายในอาคาร
หน้าที่การทำงาน: เป็นเซ็นเซอร์หลักสำหรับการตรวจจับการเคลื่อนไหวโดยไม่ขึ้นกับสภาพแสง
สนับสนุนการตรวจจับแบบคำนึงถึงความเป็นส่วนตัวมากกว่าการใช้กล้อง

#### 2.3 ระบบไฟส่องสว่างและอินเทอร์เฟซ (Illumination and Interface Module)
แหล่งกำเนิดแสง: ระบบไฟ LED
การควบคุม: ควบคุมด้วยซอฟต์แวร์ (เปิด–ปิด และปรับความสว่างได้)
หน้าที่การทำงาน: ให้แสงสว่างที่เหมาะสมและสม่ำเสมอสำหรับการทำงานของกล้อง
เพิ่มความเสถียรในการบันทึกข้อมูลภาพ
ข้อพิจารณาด้านผู้ใช้งาน: ใช้แสงความเข้มต่ำ ไม่รบกวนหรือก่อให้เกิดความไม่สบายต่อผู้สูงอายุ

#### 2.4 กลไกการหมุนกล้อง (Pan Actuation Mechanism)
ชนิดตัวกระตุ้น: เซอร์โวมอเตอร์ (Servomotor)
จำนวนองศาอิสระ: 1 องศาอิสระ (แกนหมุนแนวนอน – Pan)
วิธีการควบคุม: การควบคุมตำแหน่งด้วยสัญญาณ PWM
หน้าที่การทำงาน: 
ปรับมุมมองของกล้องในแนวนอนเพื่อติดตามการเคลื่อนไหวของผู้เข้าร่วมทดสอบ 
รักษาขอบเขตการมองเห็นของกล้องระหว่างการเคลื่อนไหว
ข้อจำกัดด้านการออกแบบ: จำกัดช่วงการหมุนเพื่อความปลอดภัยและความเสถียรเชิงกล
